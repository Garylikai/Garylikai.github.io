# Kai Li's Academic Website

Source code and content for [garylikai.github.io](https://garylikai.github.io), Kai Li's academic website.

The site is built with [Jekyll](https://jekyllrb.com/) and a repository-local copy of the [Minimal Mistakes](https://mmistakes.github.io/minimal-mistakes/) theme (version 4.22.0). GitHub Pages publishes the site from this repository.

## Site structure

- `_pages/` — profile, research, graduate-study, undergraduate-study, and course pages
- `_data/navigation.yml` — primary navigation
- `_config.yml` — Jekyll settings, author metadata, plugins, and site-wide options
- `images/` — image assets
- `assets/`, `_includes/`, `_layouts/`, and `_sass/` — theme assets and templates
- `cv.pdf` and `resume.pdf` — downloadable career documents
